# Security Policy

## Supported versions

Only the [latest release](https://github.com/DevnetraConsultancy/Sutra-Fast-Bookmark-Manager/releases/latest) receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Email **devnetraconsultancy@gmail.com** with:

- a description of the problem and its impact,
- steps to reproduce, and
- the Sutra and browser versions you used.

You will get an acknowledgement within 72 hours, and a plan for a fix once the issue is confirmed. Reporters are credited in the changelog unless they prefer otherwise.
